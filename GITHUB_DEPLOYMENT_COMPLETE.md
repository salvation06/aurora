## 🚀 Next Steps for Users

### 1. Clone Repository
```bash
git clone https://github.com/salvation06/aurora.git
cd aurora
```

### 2. Install Dependencies
```bash
npm run install:all
```

### 3. Configure Environment
```bash
cp .env.example .env
# Edit .env with your Pinata JWT token
```

### 4. Run Locally
```bash
npm run dev
```

### 5. Build for Production
```bash
npm run build:production
```

### 6. Deploy
Follow `DEPLOYMENT.md` for your chosen platform

## 🔧 Configuration Required

### Environment Variables
Users need to set their own:
```bash
PINATA_JWT=their_actual_jwt_token
NODE_ENV=production
PORT=3001
POLKADOT_NETWORK=westend
```

### Platform Deployment
Each platform requires setting the `PINATA_JWT` environment variable:

#### Heroku
```bash
heroku config:set PINATA_JWT="user_jwt_token"
```

#### Railway
Dashboard → Environment → Add Variable

#### Docker
```bash
docker run -e PINATA_JWT="user_jwt_token" aurora
```
